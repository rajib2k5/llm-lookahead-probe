Pre-registered decision rules for numeric probes:
- Coverage (C6): Wilson 95% interval of the coverage proportion. CONFIRMED if it overlaps
  [0.935, 0.965] on both configs; REFUTED if the upper bound < 0.935 on either.
- FP (C12, C14): CONFIRMED if the Wilson upper bound ≤ 0.05 OR point ≤ 0.05 with lower bound
  ≤ 0.05; REFUTED if the Wilson lower bound > 0.05.
- t-test (C7): mean honest gap over seeds / (sd / √n); |t| > 3 refutes.
